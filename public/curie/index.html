CURIE AI · OBSERVATORY

Your projects and plans, together.

Curie Observatory is Yaser’s private dashboard for project analytics, deployments, upcoming calendar events, weather, markets and server health.

The desktop companion and private web dashboard connect to a server through a VPN. This information page does not provide access to the dashboard or its data.

Google access

  • Google Analytics: read reports for the project properties selected by the owner.
  • Google Calendar: view upcoming events from the selected calendar.

The dashboard requests read-only access. It does not create, edit or delete Google Calendar events, or change Analytics properties.

Curie assistant

The owner can use calendar and project information in Curie conversations and daily briefings, with optional speech. Online integrations require a network connection; previously saved dashboard information can be viewed offline.

Curie AI also offers separate, optional Google Calendar and Gmail connectors. Those require their own authorization; connecting the dashboard does not authorize Gmail or Calendar writing. See the privacy information for the distinction.
