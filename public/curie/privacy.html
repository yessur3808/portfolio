How Curie uses Google data

This page describes Google connections in Yaser’s private Curie AI assistant and Curie Observatory dashboard. Each connector requires authorization for its own permissions.

Information accessed

With the owner’s authorization, the dashboard reads upcoming events from the configured Google Calendar, including event titles, times, locations and links. It reads Google Analytics reports for configured properties, including daily page or screen views and session totals.

The requested permissions are calendar.events.readonly and analytics.readonly. These permissions do not allow the dashboard to create, modify or delete calendar events or change Analytics properties.

Separate Curie AI connectors

Outside the dashboard, optional Curie AI connectors can read Google Calendar information for an agenda and read Gmail messages when the owner separately authorizes those features. Separate write workflows can request Calendar event editing or Gmail sending permission and require an action preview and approval. These permissions are not requested by the dashboard connection.

Information returned by these connectors can be used in the owner’s requested assistant tasks. Curie AI uses the operating-system credential store for its connector refresh tokens; the dashboard uses the restricted server files described below.

Use and storage

The dashboard uses this information to display the calendar and project reports and to provide context for Curie conversations and daily briefings. It caches information on the private server and may save dashboard snapshots on paired devices and in the browser for offline use.

Google OAuth credentials and refresh tokens are stored in restricted files on the owner’s server. The dashboard does not include them in its source repository or desktop installers, and does not return them through the settings interface.

Curie processing

Relevant dashboard information can be sent to the owner’s configured Curie AI service to answer questions and prepare briefings. That service may use an external AI provider according to its configuration. Optional voice features also use the configured speech services. The owner should review those services before including sensitive calendar information.

Sharing and control

The dashboard has no advertising or data-sale feature. Google data is used for the owner’s dashboard and requested assistant features. People with access to a paired device or the dashboard’s access key may be able to view saved information.

The owner can disconnect Google in dashboard settings, revoke the app’s access in Google Account connections, and clear the browser’s saved snapshot in settings. Disconnecting does not erase copies already saved on other devices or in backups; remove those copies separately.
